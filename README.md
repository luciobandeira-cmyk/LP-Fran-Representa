# Fran Representa - landing page

Landing page B2B da Fran Representa (Francieli Furlanetto, representante comercial): 14 marcas de utilidades domésticas, mesa posta, churrasco, térmicos e brinquedos no atacado para lojistas com CNPJ.

Site estático, publicado pelo GitHub Pages a partir da raiz da branch `main`.

## Estrutura

- `index.html`: a página completa (HTML, CSS e JavaScript no mesmo arquivo)
- `assets/img/`: fotos dos produtos, retrato da Fran, logo, favicon e imagem de compartilhamento
- `assets/video/`: vídeos do topo (MP4, sem som)
- `.nojekyll`: publica os arquivos como estão, sem processamento do Jekyll

## Pendências de conteúdo

Os trechos marcados em destaque tracejado na página aguardam confirmação da Fran: números, depoimentos, nomes das 5 marcas restantes, razão social, CNPJ, endereço, política de privacidade e logos das marcas.

## Formulário

Hoje o formulário valida os dados e mostra a mensagem de sucesso com o link do WhatsApp. Para receber os cadastros, ligar o envio a um CRM, planilha ou webhook no ponto marcado no código ("Na publicação: enviar lead ao CRM").
